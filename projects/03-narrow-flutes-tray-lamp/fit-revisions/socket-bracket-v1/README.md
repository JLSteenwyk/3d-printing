# Socket bracket V1

Print [socket_bracket_40mm_PETG.3mf](../../models/socket_bracket_40mm_PETG.3mf). This is a standard geometry-only 3MF with millimeter units, not a configured Bambu Studio project. Choose the P2S printer, PETG filament and supports in Bambu Studio; slice and inspect before printing. Archive/XML and round-trip geometry checks passed; Bambu Studio import has not been tested.

The bracket uses the physically accepted 40 mm bore and 3 mm clamping plate. Complete bracket fit is pending. The modeled bracket, provisional socket shape and bulb clear the existing lamp body; the socket shape remains photo-based. Cord restraint and thermal validation are unfinished. Test unplugged before printing the lamp body.

See [print and fit instructions](PRINT_AND_FIT.txt), [validation](validation.json), and [CAD preview](bracket-preview.png). The [generator](generate.py) writes STL, validation, instructions and preview beside itself. The committed 3MF carries the same mesh as the STL.
