# TriLamp — Organic Lantern shade and matching cap

A softer replacement for the tall TriLamp shade: gently bowed sides, flowing
shallow waves, varied small openings, and a fine fuzzy finish. Designed for opaque
PLA in Desert Tan or other muted colors, including grey-blue.

**[Current design, cap download, and full-set build instructions](variants/organic-lantern/)**

## What is available here

- Our shade generator, cap design, stand extraction and project-building code.
- The independently designed matching cap, in printable STL and P2S 3MF formats.
- Previews and validation reports for the current design.
- Instructions for creating the full five-part set locally from the original file.

The original **TriLamp by XYZilla** is available on
[MakerWorld, model 772090](https://makerworld.com/en/models/772090).
Download the original stand files there; this public repository does not mirror
them. The source file identifies the Standard Digital File License, which
restricts redistribution of the original models and derivatives. Consequently,
source-derived shade meshes and the full-set 3MF are generated locally and
excluded from Git unless separate publication permission is obtained.

The three original tall-stand components are `TriLampStand.stl`,
`TriLampStand2.stl`, and `TriLampStand3.stl` (plate 6 of the supplied all-variants
project). The local build extracts them without changing their shape, preserving
the original print orientation.

[Previous Soft Spiral version](variants/soft-spiral/) remains available.
